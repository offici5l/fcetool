---

### CLI

**Installation**

```sh
pip install fcetool
```

**Usage**

```sh
fcetool <URL> <FILENAME> <OUTPUT_DIR>
```

- `URL`: URL of the ROM/ZIP
- `FILENAME`: Target filename to extract
- `OUTPUT_DIR` *(optional)*: Output directory (default: `.`)
